## 简介
这是一个基于 Actix-web 的 Web 应用程序

这是金华职业技术大学的阳光长跑快速爬取工具，用于从 SunnySport.org.cn 获取阳光长跑数据

## 使用方法
### 构建
```bash
cargo build
```
### 运行
```bash
cargo run
```
